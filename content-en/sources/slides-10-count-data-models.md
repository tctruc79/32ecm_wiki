## Role

Topic 10 slide deck — the dependent variable is a non-negative integer (a count of how many times an event occurs). All the theory (Poisson, Negative Binomial, Zero-Inflated NB) extracted fully via text.

## Example data

Demand for COVID-19 vaccine purchases (variable `dhh`: number of doses bought for the household) — the same 377-person Ho Chi Minh City 2020 survey used in [[concepts/binary-response-models]] (Topic 7), only swapping the dependent variable from a binary decision (`dself`) to a purchase count (`dhh`).
